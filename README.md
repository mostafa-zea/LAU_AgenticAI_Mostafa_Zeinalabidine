Before starting, install Python, Jupyter and Blender.

This project was tested with Python 3.14.7 and Blender 5.1.2.

You will also need  your own ChatGPT account with access to a chosen model.

Keep all project files and folders together, including requirements.txt, agentic_scenography, blender and outputs.

Run the cells from top to bottom.

Open CLEAN_Agentic_Scenography.ipynb in Jupyter and follow the step-by-step instructions inside. 

Run the cells from top to bottom, starting with the installation of the required Python packages.

New results are saved in a new folder inside outputs.



The Test 1, Test 2 and Test 3 notebooks contain previously run sequences using different settings and instructions. 
Their saved results can be viewed without running them again. 
Supporting files are in outputs, and the results and analysis are discussed in the accompanying report.
